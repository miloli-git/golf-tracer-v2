# Example

`clip.mp4` is a tiny synthetic swing clip (generated by `tests/fixtures/make_fixture.py`) used by the CI smoke test. It exercises the full pipeline mechanically — impact detection, tracking, and reel composition:

```
golftracer reel examples/clip.mp4 --out out/
```

Expected outputs in `out/`: `clip_impacts.json`, `clip_session.json`, `clip_reel.mp4`, plus `clips/` and `qa/`. Being synthetic, it validates plumbing, not tracking quality — for a real reel, film under the capture guide in `LESSONS.md` §20.
